# The manuscript

This directory holds the scientific manuscript. It is a different product from
`report/`, and the difference is deliberate.

| | `report/report.tex` | `paper/paper.tex` |
|---|---|---|
| Authored by | the pipeline, end to end | a person |
| Prose | a thin restatement of artefacts | an argument |
| Scope | every analysis the pipeline computes | only the evidence the argument needs |
| Regenerated by | `make pipeline` | never — it is source |

## Why the manuscript is split in two

The repository's central contract is that no number is transcribed by hand. The
report satisfies that by being generated in full. A paper cannot be generated in
full: it needs a research question, a literature position and a narrative that no
template produces.

So the manuscript is split.

```text
paper/
├── main.tex             authored — preamble and document structure
├── sections/            authored — the prose, one file per section
├── references.bib       authored — every entry checked at the publisher
└── generated/           WRITTEN BY THE PIPELINE — never edit
    ├── macros.tex       every quantity the prose may cite
    └── tab_*.tex        every table the paper includes
```

`generated/macros.tex` is the bridge. Each quantity the prose needs is exposed as a
LaTeX command, so a sentence reads

```latex
The Social Security balance is positive in \SsfPositiveYears\ of \PanelYears\ years.
```

rather than `43 of 49`. Three things follow:

1. a stale number cannot survive in the text — if an artefact changes, the sentence
   changes with it;
2. a macro that no longer exists **fails the build** rather than rendering as
   nothing, so the guarantee is enforced rather than hoped for;
3. the authored prose stays reviewable as prose, because the numbers are named.

Figures are not copied here. `main.tex` sets `\graphicspath` to
`../outputs/figures/`, so the paper, the report and the notebooks all show the same
files and a figure cannot drift between them.

## Building

```bash
make pipeline    # writes paper/generated/
make paper       # compiles paper/paper.pdf
```

`paper/paper.pdf` is committed, so the manuscript is readable from the repository
without a LaTeX installation. Rebuild and commit it alongside any change that
affects it.

## Editing rules

- Edit `main.tex`, `sections/*.tex` and `references.bib` freely.
- Never edit `generated/`. Change
  `src/portugal_fiscal_balance/reporting/paper.py` and rerun the pipeline instead.
- Adding a number to the prose means adding a macro in that module first. If you
  find yourself typing a digit into a section file, that is the signal.
- Add a bibliography entry only after checking it at the publisher, RePEc or the
  issuing institution. A secondary citation is not sufficient.
